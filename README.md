## Tecnologias utilizadas 

En las clases seleccionadas se ha utilizado el lenguaje Python, con las librerias:
* '**Pandas**'
* '**Matplotlib**'

---
## Instrucciones para ejecutar el codigo

##### 1. Requisitos Previos:
Asegurate de tener **Python** instalado en tu sistema. Luego, instala las bibliotecas necesarias:

```language
pip install pandas matplotlib
```


El script `clase11.0&12-Pandas&Matplotlib.py` requiere un archivo CSV llamado **'train.csv'**.

##### 2. Ejecución
Una vez que tengas los archivos Python y el train.csv en el mismo directorio, puedes ejecutar cada script desde la línea de comandos:

**Ejecutar la clase de limpieza de datos**
```language
python clase9.0-Pandas.py
```


**Ejecutar la clase de selección y agrupación de datos**

```language
python clase10.0-Pandas&Matplotlib.py
```


**Ejecutar la clase de visualización de datos (requiere train.csv y mostrará dos gráficos)**

```language
python clase11.0&12-Pandas&Matplotlib.py
```
